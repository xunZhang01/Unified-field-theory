Overview
This repository hosts the manuscript and supplementary materials for FBGT (Filter–BIBD–Gauge–Topos), a unified field theory framework grounded in semantic geometry and cognitive topology. The framework is built on twenty axioms (A.0–A.20) and projected onto a four-dimensional Poincaré manifold.

FBGT extends our earlier work, The Topological Structure of Time in General Relativity (Version v1, DOI: 10.5281/zenodo.22282743, September 3, 2026).

Core Claim
General relativity is not an independent theory but the inevitable manifestation of FBGT at n = 4 under BIBD balance. Unified field theory is not an external patchwork but the natural result of:

all fields as sections over a function ring K,

all gauge groups as subgroups of GA,

all dynamics governed by a unified filter equation.
